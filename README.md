# Better Minimap

This mod adds a few QoL features to the minimap that give it more **customizability** for a better experience.

All the features are toggleable, so you can disable those you don't want.

I'll *probably*™ add more features later on.


## Features

- **Side Objectives Always Revealed:** Reveals what each side objectives are without having to get close to them
- **Locked Minimap Rotation:** Locks the minimap's rotation with *north* being always up
- **Minimap Zoom:** Adjustable minimap zoom level to your preference


## Settings

| Setting                | Mod Default | Base Game Default | Description                                                                    |
|------------------------|-------------|-------------------|--------------------------------------------------------------------------------|
| Reveal Side Objectives | true        | false             | If true, reveals what each side objectives are without having to go near them. |
| North Up               | true        | false             | If true, north will always point upwards.                                      |
| Zoom Amount            | 160         | 80                | Changes how zoomed in the minimap is. (lower = more zoomed in)                 |
