# Changelog


## 1.0.0 (2026-10-29)

### Features
- Option to make the side objectives appear as what they actually are instead of appearing as question marks by default
- Option to lock the minimap's rotation with North being always up
- Option to change how zoomed in the minimap is

### Features
- **Reveal Side Objectives:** Display side objectives using their actual icons instead of question marks
- **Fixed Minimap Rotation:** Keep north oriented upward on the minimap
- **Minimap Zoom:** Adjust the minimap's zoom level to your preference

### Features
- **Side Objectives Always Revealed:** Reveals what each side objective is without having to get close to it
- **Fixed Minimap Rotation:** Lock the minimap's rotation with *north* being always up
- **Minimap Zoom:** *Adjustable* minimap zoom level to your preference
